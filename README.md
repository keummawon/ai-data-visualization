# 숫자로 보는 AI 학습 데이터

인공지능이 이미지, 소리, 텍스트, 수치 데이터를 어떻게 숫자로 바꿔 학습하는지 직접 눌러 보며 이해하는 중학생 수업용 웹사이트입니다.

- **이미지**: 픽셀을 눌러 RGB·밝기 숫자를 확인하고 바꿔 보기, 비슷한/다른 숫자 패턴 비교
- **소리**: "안녕하세요" 소리의 떨림을 일정한 간격으로 재서 숫자로 바꾸기, 목소리별 패턴 비교
- **텍스트**: 문장을 토큰과 번호로 나누기, 단어 임베딩(좌표와 화살표)으로 뜻의 가까움 보기
- **수치**: 기온 데이터의 크기·차이·증가와 감소, 기온과 판매량의 관계로 예측하기

그림, 소리, 표의 값은 원리를 보여 주기 위해 만든 예시입니다.
